Lab Summary

In this lab, we learned about intensity transformations and histogram processing in image processing. We applied thresholding using different threshold values to convert a grayscale image into binary images. We also worked with histograms using the moon image, including contrast stretching, histogram equalization, and histogram matching. These techniques helped us understand how image intensity and contrast can be adjusted and how the distribution of pixel intensities can be modified. We used Python libraries such as OpenCV, NumPy, Matplotlib, and scikit-image to implement and visualize the different image processing techniques.
